## My Inventory — Sistem Manajemen Inventaris Barang

Aplikasi web untuk mengelola inventaris barang perusahaan, mencakup pencatatan barang masuk/keluar, peminjaman, dan laporan stok.

🌐 **Demo Online:** [demo-myinventory.arifsiddikm.com](https://demo-myinventory.arifsiddikm.com)

> Demo login: `admin@mail.com` / `password`

---

### Fitur

- 📦 Manajemen inventaris barang
- 📥 Pencatatan barang masuk & keluar
- 🔄 Sistem peminjaman barang (request → approve → return)
- 📊 Laporan & export PDF / Excel
- 👥 Manajemen user dengan role Admin & Karyawan
- 📋 Activity log & notifikasi stok menipis

---

### How to use?

- Clone or download source code
- Open project, run `composer install`
- Run `npm install && npm run build`
- Copy file env to `.env` and setting your password
- Run `php artisan key:generate`
- Run `php artisan migrate --seed`
- Run `php artisan storage:link`
- Run `php artisan serve`
- Open `http://localhost:8000` on your browser
- Enjoy!
